# 2026-05-19 Refactor

This refactor keeps Surfboard behavior-preserving except for correctness fixes called out below. The safety contract remains unchanged:

- YAML is authoritative for local intended state.
- SQLite stores metadata only, never work item field content.
- ADO `System.Rev` is authoritative for remote state.
- Every update patch keeps the `/rev` `test` op.
- No background pull/push or automatic retry is introduced.
- All real ADO mutation remains explicitly user-triggered.

## Completed Scope

1. Restored a green baseline:
   - Fixed Fastify inject typing in scaffold route tests.
   - Added deterministic watcher readiness and polling-backed file events.
   - Corrected operation summaries so push creates count as `created`, push updates count as `updated`, pulls count as `pulled`, and skips do not count as mutations.
   - Made `getWorkItems` use the ADO `wit/workitemsbatch` POST contract with IDs and `$expand`, with a narrow GET fallback for unavailable batch endpoints.

2. Separated shared API contracts:
   - Added `src/shared/api.ts` for route DTOs.
   - Updated frontend, tests, and smoke scripts to import browser-facing DTOs from shared code.
   - Added a frontend API contract test to prevent `src/frontend/*` from importing server modules.

3. Clarified workspace/cache boundaries:
   - Split workspace discovery, validation, and cache indexing helpers while preserving `scanWorkspace` and `indexWorkspace`.
   - Centralized selector and parent-child matching in `src/server/workItemRefs.ts`.
   - Added tests for duplicate issue attribution and preserving accepted baselines during indexing.

4. Decomposed sync support code:
   - Extracted result tally/rollup helpers, audit writing, remote diagnostics, and selector helpers out of `syncEngine.ts`.
   - Kept public pull/push function names and route behavior stable.

5. Slimmed route and frontend adapters:
   - Centralized selector and audit limit parsing in routes.
   - Added `src/frontend/apiClient.ts` for typed fetch wrappers.
   - Kept render helpers pure and frontend route DTOs shared.
